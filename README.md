## [ 채팅기능 ]
### Socket.io 사용. 

### 로그인 후 메인페이지 : 사이드바에 게시판 및 현재 참여중인 채팅목록이 나옵니다.

![2](https://github.com/user-attachments/assets/dafa243c-cc5e-4e93-9351-f11c33855a68)

### 사이드바 채팅방 목록 :  기존 채팅목록이 보여집니다.

### 채팅 : 두사람 모두 채팅방에 입장되어 있을때, 실시간 채팅이 가능합니다.
